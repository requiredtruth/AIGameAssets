## Request a direction

After confirmation, open a GitHub issue containing:

1. the asset and exact network;
2. the public transaction hash; and
3. the specific feature, test, documentation area, or project direction you want expanded.

The first GitHub issue claiming an unclaimed confirmed inbound transaction hash receives the operational request attribution for that transaction. This is not cryptographic proof that the claimant controlled the sending wallet. A hash attributed to an earlier issue cannot be reused.

A donation can direct what additional work is requested, but it does not purchase ownership, investment returns, a delivery deadline, or acceptance of unsafe, illegal, proprietary, or out-of-scope work. Funding is counted only after a transaction is publicly confirmed on the relevant chain.
