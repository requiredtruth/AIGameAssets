# Contributing

Useful, tested contributions are welcome.

1. Keep generated content engine-neutral and small enough for an 8-bit-style RPG.
2. Add or update tests for behavior changes.
3. Run `python -m unittest discover -s tests -v`.
4. Do not commit API keys, model weights, generated databases, copied game content, or fabricated performance numbers.
5. Explain what changed and why in the pull request.
